Wie Ressourcen in die linke Liste kommen — Gruppe laden

Der dritte Weg (neben automatischen Recents und angepinnten Favoriten): über die Omnibox eine ganze Gruppe als Block in die Stepping-Liste holen — so kommt „alle Räume von Gebäude C" auf einen Schlag rein, ohne Dauer-Baum.

1 Omnibox: Gruppe finden → „in Liste laden"
🔍

Die Omnibox liefert nicht nur Einzel-Räume, sondern einen Gruppen-Treffer „Räume C-Bau (12)" mit der Aktion „in Liste laden". Auch ein Eltern-Knoten (Gebäude C, oder ein Studiengang → seine Kurse) bietet das.
↓ in Liste laden

Die 12 Räume stehen jetzt als Gruppe in der Liste. Single-Klick auf einen → seine Woche (ersetzt), Klick auf den nächsten → nächste. Das ist der Durchstepp-Rhythmus.

„× leeren" wirft die Gruppe wieder raus. Eine geladene Gruppe lässt sich auch als Saved View sichern, wenn man sie öfter braucht.

Die drei Quellen der Liste: „Zuletzt" = automatisch (jede angesehene Ressource) · „Favoriten" = per ★ angepinnt · „Gruppe" = hier geladen. Alle drei füttern dasselbe Durchsteppen.
